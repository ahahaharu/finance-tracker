# Дизайн-система — finance-tracker

Направление: **Ledger** — интерфейс как разлинованная бухгалтерская книга.
Тёплая бумага, чернильный текст, тонкие линейки, плотные таблицы, моноширинные
числа. Единственный источник цвета в интерфейсе — категории пользователя.

Документ обязателен к соблюдению. Всё, что ему противоречит, считается
ошибкой ревью.

---

## 1. Цветовые токены

Объявляются в `app/globals.css`. Прямое использование шестнадцатеричных
значений и палитры Tailwind (`slate-*`, `gray-*`, `blue-500` и подобных)
в компонентах запрещено.

```css
:root {
  --bg: #fbfaf8;
  --surface: #ffffff;
  --sunken: #f4f2ed;
  --line: #e4e0d8;
  --line-strong: #cfc9bd;
  --ink: #1a1917;
  --ink-muted: #6b665d;
  --ink-faint: #9a948a;
  --positive: #2f6b4f;
  --warning: #8a6a2f;
  --negative: #a8442a;
  --radius: 6px;
}

[data-theme='dark'] {
  --bg: #141311;
  --surface: #1b1a17;
  --sunken: #100f0e;
  --line: #2c2a26;
  --line-strong: #3d3a34;
  --ink: #edeae3;
  --ink-muted: #9a948a;
  --ink-faint: #6b665d;
  --positive: #6fa98a;
  --warning: #c4a05c;
  --negative: #d98368;
}
```

Назначение токенов:

| Токен           | Где применяется                                                 |
| --------------- | --------------------------------------------------------------- |
| `--bg`          | канва страницы                                                  |
| `--surface`     | приподнятые области: блок общего баланса, поповеры              |
| `--sunken`      | шапка таблицы, hover строки, заголовки групп, дорожка прогресса |
| `--line`        | hairline-разделители, границы таблиц                            |
| `--line-strong` | границы полей ввода и вторичных кнопок                          |
| `--ink`         | основной текст, фон primary-кнопки, заполнение прогресса        |
| `--ink-muted`   | подписи, вторичный текст                                        |
| `--ink-faint`   | плейсхолдеры, метаданные, суммы в базовой валюте                |
| `--positive`    | суммы доходов                                                   |
| `--warning`     | бюджет израсходован на 80–100 %                                 |
| `--negative`    | суммы расходов, ошибки валидации, превышение бюджета            |

Правило окраски сумм: красится **только само число**, не строка и не её фон.

## 2. Палитра категорий

Цвет категории — единственный источник цвета в интерфейсе помимо служебных
токенов выше. Он сквозной: одна и та же категория окрашена одинаково в списке
операций, в аналитике и в бюджетах.

Набор фиксирован. При создании категории цвет выбирается из него; произвольный
ввод цвета не предусмотрен.

```css
--cat-1: #8c6a4a;
--cat-7: #4f7a6a;
--cat-2: #6e7f5c;
--cat-8: #9a6b52;
--cat-3: #5c7a8c;
--cat-9: #6a7c92;
--cat-4: #8a6070;
--cat-10: #87735e;
--cat-5: #7a6e9a;
--cat-11: #5f8a7e;
--cat-6: #a08048;
--cat-12: #96666a;
```

Все двенадцать имеют близкую светлоту: ни один не выпрыгивает из ряда
и не притягивает внимание сильнее остальных. В тёмной теме применяются те же
оттенки, осветлённые примерно на 25 %.

Где применяется цвет категории:

- точка 6 px в строке операции;
- заливка бара в разбивке расходов по категориям;
- точка рядом с наименованием категории в списке бюджетов и в справочнике.

Где не применяется: фон строк, фон карточек, границы, текст.

## 3. Типографика

| Роль                   | Гарнитура     | Размер | Вес                           |
| ---------------------- | ------------- | ------ | ----------------------------- |
| Интерфейсный текст     | IBM Plex Sans | 13     | 400                           |
| Подписи, метаданные    | IBM Plex Sans | 12     | 400                           |
| Мелкие метки, статусы  | IBM Plex Sans | 11     | 400                           |
| Заголовок секции       | IBM Plex Sans | 13     | 500, `letter-spacing: 0.04em` |
| Заголовок страницы     | IBM Plex Sans | 20     | 500                           |
| Числа в таблицах       | IBM Plex Mono | 13     | 400                           |
| Крупные суммы          | IBM Plex Mono | 32     | 400                           |
| Общий баланс (дашборд) | IBM Plex Mono | 44     | 400                           |

Шкала размеров закрыта: **11 / 12 / 13 / 14 / 20 / 32 / 44**. Промежуточных
значений нет.

Веса: только **400 и 500**. Значения 600 и выше запрещены.

Все денежные значения выводятся с `font-variant-numeric: tabular-nums` —
без этого колонки сумм смещаются между строками.

Подключение через `next/font/google`, подмножества `latin` и `cyrillic`,
веса 400 и 500.

## 4. Пространство и плотность

| Параметр                     | Значение |
| ---------------------------- | -------- |
| Базовая единица              | 4 px     |
| Высота строки таблицы        | 44 px    |
| Внутренний отступ ячейки     | 0 12 px  |
| Высота поля ввода и кнопки   | 34 px    |
| Отступ страницы              | 24 px    |
| Отступ между секциями        | 32 px    |
| Ширина сайдбара              | 264 px   |
| Максимальная ширина формы    | 320 px   |

Радиус скругления — `var(--radius)` (6 px) для всех элементов без исключений.
`rounded-xl`, `rounded-2xl`, `rounded-full` запрещены; единственное
исключение — аватар.

Тени запрещены. Глубина создаётся границей `1px solid var(--line)` и сменой
фона на `--surface` либо `--sunken`. Исключение — выпадающие меню и поповеры.

На одной странице **не более одного элемента на `--surface`**. На дашборде
это блок общего баланса; на остальных экранах приподнятых элементов нет.

Область контента занимает всю ширину окна за вычетом сайдбара: списки
операций широкие, и ограничивать их незачем. Ограничение 320 px остаётся
только у форм — растянутое на весь экран поле ввода читается плохо.

Сайдбар закреплён на всю высоту окна и не зависит от высоты контента.
Сверху — название программы, затем пункты навигации, снизу — учётная запись
и переключатели языка и темы.

Анимации: длительность 120 мс, `ease-out`, только `opacity` и `transform`
в пределах 4 px. Пружинные и отскакивающие эффекты запрещены.

## 5. Компоненты

### 5.1. Кнопки

| Вариант     | Оформление                                                              |
| ----------- | ----------------------------------------------------------------------- |
| Primary     | фон `--ink`, текст `--bg`, высота 34 px, без границы                    |
| Secondary   | прозрачный фон, граница `1px --line-strong`, текст `--ink`              |
| Ghost       | прозрачный фон, без границы, hover — фон `--sunken`                     |
| Destructive | текст `--negative`, без заливки; заливка только в диалоге подтверждения |

На одном экране допускается **не более одной** primary-кнопки.

### 5.2. Поля ввода

Label сверху, 12 px, `--ink-muted`. Поле — высота 34 px, граница
`1px --line-strong`, фон `--bg`. Фокус — `outline: 1px solid var(--ink)`
с `outline-offset: 1px`; цветное свечение запрещено. Ошибка — граница поля
`--negative` плюс текст 12 px `--negative` под полем.

### 5.3. Компонент `<Amount />`

Единственный допустимый способ вывода денежной суммы. Обязанности:

- IBM Plex Mono, `tabular-nums`;
- знак `+` или `−` перед числом;
- цвет `--positive`, `--negative` либо `--ink` в зависимости от типа;
- форматирование через `Intl.NumberFormat` с учётом локали и валюты;
- при валюте, отличной от базовой, — вторая строка 11 px `--ink-faint`
  с суммой в базовой валюте.

Прямой вывод чисел в JSX запрещён.

### 5.4. Компонент `<CategoryDot />`

Точка 6 px цвета категории. Применяется везде, где упоминается категория.
Рядом — наименование 12 px `--ink-muted`. Иконки и эмодзи вместо точки
запрещены.

### 5.5. Компонент `<BudgetStatus />`

Метка 11 px с приглушённой заливкой, показывающая исполнение лимита:

| Доля        | Текст      | Оформление                                                 |
| ----------- | ---------- | ---------------------------------------------------------- |
| до 80 %     | в норме    | текст `--ink-muted`, фон `--sunken`                        |
| 80–100 %    | на пределе | текст `--warning`, фон — тот же цвет с прозрачностью 12 %  |
| свыше 100 % | превышен   | текст `--negative`, фон — тот же цвет с прозрачностью 12 % |

Радиус `var(--radius)`, внутренние отступы 2 px по вертикали и 6 px
по горизонтали.

### 5.6. Таблица операций

- Колонки: время · описание · категория · счёт · сумма.
- Сумма прижата вправо.
- Категория выводится через `<CategoryDot />`.
- Группировка по дням: строка-заголовок с фоном `--sunken`, дата слева,
  итог за день справа.
- Hover строки — только смена фона на `--sunken`, без сдвигов и теней.
- Итог по текущему набору фильтров — в закреплённом подвале таблицы.

### 5.7. Дашборд

1. **Блок общего баланса** — единственный элемент на `--surface`
   с границей `1px --line`. Внутри: подпись 12 px, сумма 44 px моноширинным,
   дельта за месяц 12 px `--ink-muted`.
2. Три показателя (доход, расход, сальдо) в ряд, разделённые вертикальными
   hairline. Без карточек и без иконок.
3. Счета — список, не сетка карточек. Для счёта в неосновной валюте —
   вторая строка с суммой в валюте отчётности.
4. Бюджеты — список: наименование с `<CategoryDot />`, отношение
   «потрачено / лимит» моноширинным, `<BudgetStatus />`, прогресс-бар
   высотой 3 px. Дорожка `--sunken`, заполнение — `--ink`, при превышении —
   `--negative`.
5. Расходы по категориям — горизонтальные бары высотой 14 px, залитые
   собственным цветом категории, отсортированные по убыванию, с суммой
   справа от бара.
6. Последние восемь операций в табличном стиле.

### 5.8. Графики

Разбивка по категориям — горизонтальные бары в цвете категории.
Помесячная динамика — столбчатая диаграмма, заливка `--ink-muted`,
текущий месяц `--ink`.

Круговые и кольцевые диаграммы запрещены.

### 5.9. Состояния

- **Пустое:** строка текста 13 px `--ink-muted` плюс одна secondary-кнопка.
  Иллюстрации, эмодзи и центрированные блоки во весь экран запрещены.
- **Загрузка:** скелетоны точной геометрии реальных строк — рамка таблицы,
  шапка и строки высотой 44 px с прямоугольниками `--sunken` на месте
  значений. Спиннер по центру запрещён. Скелетон подменяет **только данные**:
  заголовок страницы, кнопки и фильтры остаются на месте.
- **Ошибка:** текст с описанием причины плюс кнопка повтора действия.

## 6. Запреты (проверяются на ревью)

1. Цвета вне CSS-переменных, включая палитру Tailwind напрямую.
2. Цвет категории где-либо, кроме точки, бара диаграммы и метки категории.
3. Градиенты — везде.
4. `box-shadow` — кроме поповеров и выпадающих меню.
5. Более одного элемента на `--surface` в пределах страницы.
6. Радиусы, отличные от `var(--radius)`.
7. `font-weight` 600 и выше.
8. Эмодзи в интерфейсе. Иконки — `lucide-react`, 16 px, только там,
   где значок несёт смысл: пункты навигации в сайдбаре, переключатели языка
   и темы. Рядом с заголовками иконок нет.
9. Сетка карточек для списков данных вместо таблицы или списка.
10. Вывод денежных значений мимо `<Amount />`.
11. Круговые и кольцевые диаграммы.
12. Анимации длительностью более 150 мс.

## 7. Порядок работы

1. Сначала реализуются токены, палитра категорий и базовые компоненты:
   `Button`, `Input`, `Select`, `TableRow`, `Amount`, `CategoryDot`,
   `BudgetStatus`, `EmptyState`, `Skeleton`.
2. Затем полностью доводится **один** экран — список операций.
3. Остальные экраны строятся по его образцу.

Направление задано настоящим документом. Предлагать альтернативную эстетику
в ходе разработки не требуется.
