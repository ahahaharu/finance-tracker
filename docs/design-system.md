# Дизайн-система — finance-tracker

Направление: **Ledger** — интерфейс как разлинованная бухгалтерская книга.
Тёплая бумага, чернильный текст, тонкие линейки, плотные таблицы, моноширинные числа.
Декора нет: всё внимание на данные.

Документ обязателен к соблюдению. Всё, что ему противоречит, считается ошибкой ревью.

---

## 1. Цветовые токены

Объявляются в `app/globals.css`. Прямое использование хекс-значений и палитры Tailwind
(`slate-*`, `gray-*`, `blue-500` и т. п.) в компонентах запрещено.

```css
:root {
  --bg:          #FBFAF8;
  --surface:     #FFFFFF;
  --sunken:      #F4F2ED;
  --line:        #E4E0D8;
  --line-strong: #CFC9BD;
  --ink:         #1A1917;
  --ink-muted:   #6B665D;
  --ink-faint:   #9A948A;
  --positive:    #2F6B4F;
  --negative:    #A8442A;
  --radius:      6px;
}

[data-theme="dark"] {
  --bg:          #141311;
  --surface:     #1B1A17;
  --sunken:      #100F0E;
  --line:        #2C2A26;
  --line-strong: #3D3A34;
  --ink:         #EDEAE3;
  --ink-muted:   #9A948A;
  --ink-faint:   #6B665D;
  --positive:    #6FA98A;
  --negative:    #D98368;
}
```

Назначение токенов:

| Токен | Где применяется |
|---|---|
| `--bg` | канва страницы |
| `--surface` | приподнятые области; применяется редко |
| `--sunken` | шапка таблицы, hover строки, заголовки групп |
| `--line` | hairline-разделители, границы таблиц |
| `--line-strong` | границы полей ввода и вторичных кнопок |
| `--ink` | основной текст, фон primary-кнопки |
| `--ink-muted` | подписи, вторичный текст |
| `--ink-faint` | плейсхолдеры, метаданные, суммы в базовой валюте |
| `--positive` | суммы доходов |
| `--negative` | суммы расходов, ошибки валидации, превышение бюджета |

Правило окраски сумм: красится **только само число**, не строка и не её фон.

## 2. Типографика

| Роль | Гарнитура | Размер | Вес |
|---|---|---|---|
| Интерфейсный текст | IBM Plex Sans | 13 | 400 |
| Подписи, метаданные | IBM Plex Sans | 12 | 400 |
| Мелкие метки | IBM Plex Sans | 11 | 400 |
| Заголовок секции | IBM Plex Sans | 13 | 500, `letter-spacing: 0.04em` |
| Заголовок страницы | IBM Plex Sans | 20 | 500 |
| Числа в таблицах | IBM Plex Mono | 13 | 400 |
| Крупные суммы | IBM Plex Mono | 32 | 400 |
| Общий баланс (дашборд) | Instrument Serif | 44 | 400 |

Шкала размеров закрыта: **11 / 12 / 13 / 14 / 20 / 32 / 44**. Промежуточных значений нет.

Веса: только **400 и 500**. Значения 600 и выше запрещены.

Все денежные значения выводятся с `font-variant-numeric: tabular-nums` —
без этого колонки сумм «прыгают» между строками.

Подключение через `next/font/google`, подмножества `latin` и `cyrillic`.

## 3. Пространство и плотность

| Параметр | Значение |
|---|---|
| Базовая единица | 4px |
| Высота строки таблицы | 44px |
| Внутренний отступ ячейки | 0 12px |
| Высота поля ввода и кнопки | 34px |
| Отступ страницы | 24px |
| Отступ между секциями | 32px |
| Ширина сайдбара | 232px |
| Максимальная ширина контента | 1180px |

Радиус скругления — `var(--radius)` (6px) для всех элементов без исключений.
`rounded-xl`, `rounded-2xl`, `rounded-full` запрещены; единственное исключение — аватар.

Тени запрещены. Глубина создаётся границей `1px solid var(--line)` и сменой фона
на `--sunken`. Исключение — выпадающие меню и поповеры.

Анимации: длительность 120 мс, `ease-out`, только `opacity` и `transform`
в пределах 4px. Пружинные и отскакивающие эффекты запрещены.

## 4. Компоненты

### Кнопки

| Вариант | Оформление |
|---|---|
| Primary | фон `--ink`, текст `--bg`, высота 34px, без границы |
| Secondary | прозрачный фон, граница `1px --line-strong`, текст `--ink` |
| Ghost | прозрачный фон, без границы, hover — фон `--sunken` |
| Destructive | текст `--negative`, без заливки; заливка только в диалоге подтверждения |

На одном экране допускается **не более одной** primary-кнопки.

### Поля ввода

Label сверху, 12px, `--ink-muted`. Поле — высота 34px, граница `1px --line-strong`,
фон `--bg`. Фокус — `box-shadow: 0 0 0 1px var(--ink)`; цветное свечение запрещено.
Ошибка — граница поля `--negative` плюс текст 12px `--negative` под полем.

### Компонент `<Amount />`

Единственный допустимый способ вывода денежной суммы. Обязанности:

- IBM Plex Mono, `tabular-nums`;
- знак `+` / `−` перед числом;
- цвет `--positive` / `--negative` / `--ink` в зависимости от типа;
- форматирование через `Intl.NumberFormat` с учётом локали и валюты;
- при валюте, отличной от базовой, — вторая строка 11px `--ink-faint`
  с суммой в базовой валюте.

Прямой вывод чисел в JSX запрещён.

### Таблица транзакций

- Колонки: время · описание · категория · кошелёк · сумма.
- Сумма прижата вправо.
- Категория — точка 6px цвета категории плюс текст 12px. Иконки и эмодзи запрещены.
- Группировка по дням: строка-заголовок с фоном `--sunken`, дата слева,
  итог за день справа.
- Hover строки — только смена фона на `--sunken`, без сдвигов и теней.
- Итог по текущему фильтру — в закреплённом подвале таблицы.

### Дашборд

1. Общий баланс крупно, под ним — дельта за месяц мелким текстом.
2. Справа три числа (доход, расход, сальдо) в ряд, разделённые вертикальными
   hairline. Без карточек и без иконок.
3. Кошельки — список, не сетка карточек.
4. Бюджеты — список с прогресс-баром высотой 3px, прямоугольным, одноцветным;
   при превышении лимита бар окрашивается в `--negative`.
5. Последние 8 транзакций в табличном стиле.

### Графики

Расходы по категориям — горизонтальные бары одного цвета разной насыщенности,
отсортированные по убыванию, с подписью суммы справа от бара.

Круговые и кольцевые диаграммы запрещены.

### Состояния

- **Пустое:** строка текста 13px `--ink-muted` плюс одна secondary-кнопка.
  Иллюстрации, эмодзи и центрированные блоки во весь экран запрещены.
- **Загрузка:** скелетоны точной геометрии реальных строк (прямоугольники
  `--sunken` высотой 44px). Спиннер по центру запрещён.
- **Ошибка:** текст с описанием причины плюс кнопка повтора действия.

## 5. Запреты (проверяются на ревью)

1. Цвета вне CSS-переменных, включая палитру Tailwind напрямую.
2. Градиенты — везде.
3. `box-shadow` — кроме поповеров и выпадающих меню.
4. Радиусы, отличные от `var(--radius)`.
5. `font-weight` 600 и выше.
6. Эмодзи в интерфейсе. Иконки — `lucide-react`, 16px, только там,
   где значок несёт смысл; рядом с заголовками иконок нет.
7. Сетка карточек для списков данных вместо таблицы.
8. Вывод денежных значений мимо `<Amount />`.
9. Круговые и кольцевые диаграммы.
10. Анимации длительностью более 150 мс.

## 6. Порядок работы

1. Сначала реализуются токены и базовые компоненты: `Button`, `Input`,
   `TableRow`, `Amount`.
2. Затем полностью доводится **один** экран — список транзакций.
3. Остальные экраны строятся по его образцу.

Направление задано настоящим документом. Предлагать альтернативную эстетику
в ходе разработки не требуется.
